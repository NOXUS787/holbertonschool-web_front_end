# HTML, advanced

Building the structure of the Techium website using only HTML5 —
no CSS, no styling. The focus is semantic markup and correct page structure.

## Learning objectives
- Create the skeleton of an HTML5 page
- Use semantic tags: header, main, footer, article, nav, section, aside
- Know when to use div vs span
- Follow the hierarchical order of headings
- Build lists, tables, and embed media (video, audio, external content)

## Requirements
- Code must be W3C compliant
