# CSS Advanced

Advanced CSS project for the Techium website, building on the HTML
structure created in the `html_advanced` project.

## Description

This project applies styling to the Techium company website: a
homepage with hero, services, works, about us, latest news,
testimonials, and contact sections, plus a styleguide page.

## Contents

- `images/` — high resolution images for each section of the site,
  along with the site logos and favicon.
